What technologies were used to construct this website?
This entire educational platform is built strictly with HTML5 and CSS3. There are zero JavaScript files, no external framework dependencies, and no backend servers.
How is the styling organized?
CSS is organized into modular human-written stylesheets: css/style.css (core layouts and Figure 1 specifications), css/components.css (reusable UI elements), and css/responsive.css (mobile/tablet adaptability).
Can this project be opened directly in any browser?
Yes. As a pure static website, you can double-click index.html to open it directly in Google Chrome, Microsoft Edge, Mozilla Firefox, or use VS Code Live Server.
