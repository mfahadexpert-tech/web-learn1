Task 8 Flex Grow: Proportionate Free Space Distribution (1 : 2 : 1)

Three flex items with flex-grow: 1, flex-grow: 2, and flex-grow: 1.

Item 1 (grow: 1)
Item 2 (grow: 2)
Item 3 (grow: 1)
Math Calculation: Total grow units = 1 + 2 + 1 = 4. Available positive free space is divided into 4 parts. Item 2 receives 2/4 (50%) of all extra space, while Item 1 and Item 3 each receive 1/4 (25%).
Task 9 Flex Shrink: Negative Free Space Absorption

Three 300px items inside a 600px container (overflow deficit = 300px). Item 2 has flex-shrink: 2 while Items 1 & 3 have flex-shrink: 1.

300px (shrink: 1)
300px (shrink: 2)
300px (shrink: 1)
Deficit Handling: The browser calculates negative space (900px − 600px = 300px deficit). Item 2 with shrink: 2 sheds twice as many pixels as the other two items, compressing further to maintain layout integrity.

Task 13 Fractional Units (fr): 1fr Sidebar & 3fr Main Area

A 2-column layout in an 800px grid width container where sidebar occupies 1fr and main content occupies 3fr.

Sidebar (1fr = 200px / 25%)
Main Content Area (3fr = 600px / 75%)
Exact Math Calculation: Available width = 800px. Total fr units = 1fr + 3fr = 4fr. One fraction unit = 800px / 4 = 200px. Sidebar (1fr) = 200px. Main Content (3fr) = 3 × 200px = 600px.

Architectural Justification:
  • Flexbox (1-Dimensional): Chosen for the navigation bar because items flow along a single axis (row), dynamically adjusting to content length and spacing without rigid cell constraints.
  • CSS Grid (2-Dimensional): Chosen for the dashboard because items must strictly align along both horizontal rows AND vertical columns simultaneously, creating a cohesive visual matrix.
