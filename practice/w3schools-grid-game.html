W3 CSS Grid Game: Box Counter

Level 1: Spanning Box Columns

Count the vertical grid lines from left to right: [1], [2], [3], [4], [5].
Make the blue block start at box 1 (Line 1) and end at box 3 (Line 4), spanning across 3 column boxes!

How Line Counting Works:
A 4-column grid has 5 boundary lines: Line 1 (left border), Line 2, Line 3, Line 4, Line 5 (right border).
To cover 3 boxes from the start: grid-column-start: 1; and grid-column-end: 4; (or shorthand: grid-column: 1 / 4;).
#game-grid {
display: grid;
grid-template-columns: repeat(4, 1fr);
grid-template-rows: repeat(3, 1fr);
}
