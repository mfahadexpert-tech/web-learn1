1. Student Academic Marks Table with Colspan

Demonstrates semantic table tags (<thead>, <tbody>, <tfoot>) and horizontal cell merging using colspan.

HTML Code:
<table class="lecture-table">
    <thead>
        <tr>
            <th>Roll Number</th>
            <th>Student Name</th>
            <th>Subject</th>
            <th>Marks / 100</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>FA24-BSE-067</td>
            <td>Muhammad Fahad</td>
            <td>Web Technologies</td>
            <td>95</td>
        </tr>
        <tr>
            <td>FA24-BSE-068</td>
            <td>Sara Ahmed</td>
            <td>Web Technologies</td>
            <td>91</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3" style="text-align: right; font-weight: bold;">Average Class Score:</td>
            <td style="font-weight: bold;">93.0</td>
        </tr>
    </tfoot>
</table>
Expected Browser Output:
Roll Number Student Name Subject Marks / 100
FA24-BSE-067 Muhammad Fahad Web Technologies 95
FA24-BSE-068 Sara Ahmed Web Technologies 91
Average Class Score: 93.0

2. Student Course Enrollment Form

Illustrates native HTML5 validation using required, placeholder, radio buttons, and dropdown selection.

HTML Code:
<form action="#" method="POST" class="comp-form-card">
    <div class="form-group">
        <label for="st-name">Student Name:</label>
        <input type="text" id="st-name" name="st-name" placeholder="Muhammad Fahad" required>
    </div>

    <div class="form-group">
        <label for="st-email">University Email:</label>
        <input type="email" id="st-email" name="st-email" placeholder="fahad@university.edu" required>
    </div>

    <div class="form-group">
        <label>Study Program:</label>
        <div class="form-radio-group">
            <label><input type="radio" name="program" value="se" checked> BS Software Eng</label>
            <label><input type="radio" name="program" value="cs"> BS Computer Science</label>
        </div>
    </div>

    <button type="submit" class="comp-btn comp-btn-primary" style="width: 100%;">Enroll Now</button>

3. CSS Keyframe Animation Loader

Demonstrates pure CSS3 @keyframes, circular border-radius: 50%, and infinite linear rotation.

CSS Code:
.loader-ring {
    width: 44px;
    height: 44px;
    border: 4px solid #e2e8f0;
    border-top: 4px solid #2b5b9c;
    border-radius: 50%;
    animation: rotateLoop 1s linear infinite;
    margin: 10px auto;
}

@keyframes rotateLoop {
    0% { transform: rotate(0deg); }
    100% { transform: rotate(360deg); }
}
Expected Browser Output:

Animated CSS Spinner
