HTML Forms

Forms allow users to enter and submit information.

The <form> element acts as the container for form controls.

Basic Form

<form action="/register" method="post">

    <label for="name">
        Name
    </label>

    <input
        id="name"
        name="name"
    >

    <button type="submit">
        Register
    </button>

</form>

Form Output

The action Attribute

The action attribute specifies where the form data should be sent. 

<form action="/submit">

The method Attribute

The method attribute defines how form data is sent.

Method Meaning
GET Data is sent using the URL.
POST Data is sent in the request body.

GET Example

<form action="/search" method="get">

    <input name="q">

    <button>
        Search
    </button>

</form>

A submitted result can look like: 

/search?q=html

Labels

A label identifies a form control. 

<label for="email">
    Email
</label>

<input
    type="email"
    id="email"
    name="email"
>
Remember:

The value of for in the label should match the id of the input.

Other Form Controls

Forms can contain more than text inputs. 

<select>
    <option>Web Technologies</option>
</select>

<textarea></textarea>

<button>
    Submit
</button>
