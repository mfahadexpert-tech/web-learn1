Semantic HTML

Semantic HTML uses elements whose names describe the meaning of their content.

Semantic vs Non-Semantic

Non-Semantic Semantic
<div> <header>
<span> <nav>
Generic structure Meaningful structure

Common Semantic Elements

Element Purpose
<header> Intro or branding area
<nav> Navigation
<main> Main content
<section> Thematic group
<article> Self-contained item
<aside> Related content
<footer> Ending information

Semantic Page Example

<header>

    <h1>University Portal</h1>

</header>


<nav>

    Home
    Courses
    Results

</nav>


<main>

    <section>

        <h2>
            Web Technologies
        </h2>

        <article>

            <p>
                Learn HTML and CSS.
            </p>

        </article>

    </section>

    <aside>
        Related Content
    </aside>

</main>


<footer>

    University Footer

</footer>

Why Semantic HTML Matters

  • Clearer page structure
  • Better maintainability
  • Helps accessibility
  • Provides meaningful document structure
Memory Tip:

Think of a newspaper:

header → navigation → main story → side notes → footer
