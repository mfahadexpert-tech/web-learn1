HTML Div and Span

The <div> and <span> elements are generic containers.

The div Element

A div is commonly used for larger blocks or sections of content. 

<div class="card">

    <h2>HTML Course</h2>

    <p>
        Learn HTML today.
    </p>

</div>

The span Element

A span is commonly used for a small part of inline content. 

<p>

    Learn

    <span>
        HTML
    </span>

    today.

</p>

Output

Learn HTML today.

Div for Page Sections

<div id="container">

    <div id="header">
        Header
    </div>

    <div id="main-content">
        Main Content
    </div>

    <div id="footer">
        Footer
    </div>

</div>

Nesting Divs

<div class="container">

    <div class="left">
        Left Section
    </div>

    <div class="right">
        Right Section
    </div>

</div>
Remember:

Use div for larger block sections.

Use span for small inline parts of content.
