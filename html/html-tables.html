HTML Tables

HTML tables are used for data that has relationships between rows and columns.

Basic Table

<table>

    <tr>
        <th>Name</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>85</td>
    </tr>

    <tr>
        <td>Sara</td>
        <td>91</td>
    </tr>

</table>

Output

Name Marks
Ali 85
Sara 91

Common Table Elements

Element Purpose
<table> Creates the table
<tr> Creates a row
<th> Header cell
<td> Data cell

Professional Table Structure

Tables can also use:

  • <caption>
  • <thead>
  • <tbody>
  • <tfoot>
<table>

    <caption>
        Student Marks
    </caption>

    <thead>

        <tr>
            <th>Name</th>
            <th>Marks</th>
        </tr>

    </thead>

    <tbody>

        <tr>
            <td>Ali</td>
            <td>85</td>
        </tr>

    </tbody>

</table>

Colspan

Colspan lets one cell cover multiple columns. 

<td colspan="2">
    Merged Column
</td>

Rowspan

Rowspan lets one cell cover multiple rows. 

<td rowspan="2">
    Merged Row
</td>
Important:

Tables should be used for tabular data, not for page layout.
