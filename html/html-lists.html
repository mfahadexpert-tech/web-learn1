HTML Lists

Lists help organize information into easy-to-read items.

Unordered List

An unordered list uses the <ul> element. 

<ul>

    <li>HTML</li>
    <li>CSS</li>

</ul>

Output

  • HTML
  • CSS

Ordered List

An ordered list uses numbers. 

<ol>

    <li>Open browser</li>
    <li>Enter URL</li>

</ol>
  1. Open browser
  2. Enter URL

List Elements

Element Purpose
<ul> Unordered list
<ol> Ordered list
<li> List item

Description List

A description list is useful when you have a term and its definition. 

<dl>

    <dt>HTML</dt>

    <dd>
        Structures web content.
    </dd>

    <dt>CSS</dt>

    <dd>
        Styles web content.
    </dd>

</dl>
HTML
Structures web content.
CSS
Styles web content.
Remember:

Use lists when information should be shown in clear, scan-friendly items.
