HTML Attributes

Attributes provide additional information about HTML elements.

Basic Attribute Syntax

<tag attribute="value">

Example

<a href="https://example.com">
    Visit Website
</a>

Here:

  • a is the element.
  • href is the attribute.
  • https://example.com is the attribute value.

Image Attributes

<img
    src="student.jpg"
    alt="Student studying"
    width="400"
>

Common Image Attributes

Attribute Purpose
src Tells where the image comes from.
alt Provides alternative text.
width Controls the displayed width.

Attributes in Forms

<input
    type="email"
    name="email"
    placeholder="Enter your email"
    required
>

In this example:

  • type defines the type of input.
  • name identifies the field.
  • placeholder provides a hint.
  • required prevents empty submission.

Coding Style

The course material recommends using lowercase tag names and attributes.

Recommended: 
<input
    type="email"
    name="email"
>

Attribute values should normally be written inside quotation marks.
