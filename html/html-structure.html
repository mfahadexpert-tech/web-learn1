HTML Document Structure

An HTML page has a predictable structure.

The main parts include:

  • DOCTYPE
  • html
  • head
  • body

Basic HTML Structure

<!DOCTYPE html>

<html>

<head>

    <title>
        My Website
    </title>

</head>

<body>

    <h1>
        Welcome
    </h1>

    <p>
        Hello World
    </p>

</body>

</html>

DOCTYPE

The DOCTYPE declaration tells the browser that the document is an HTML document. 

<!DOCTYPE html>

The html Element

The <html> element contains the complete HTML document.

The head Element

The head contains information about the page. 

<head>

    <title>
        My Website
    </title>

</head>

The body Element

The body contains the visible content displayed in the browser. 

<body>

    <h1>Welcome</h1>

    <p>
        This content is visible.
    </p>

</body>

HTML Elements Form a Tree

Elements can exist inside other elements. This creates a parent and child structure. 

<body>

    <section>

        <h2>HTML</h2>

        <p>
            Learn HTML today.
        </p>

    </section>

</body>

Correct Nesting

HTML elements should close in reverse order.

Correct: 
<p>
    <strong>
        Important
    </strong>
</p>
Wrong: 
<p>
    <strong>
        Important
</p>
    </strong>
