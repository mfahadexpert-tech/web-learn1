HTML Links

Hyperlinks connect web pages and resources.

HTML uses the <a> element to create a link.

Basic Link

<a href="https://example.com">
    Visit
</a>

Absolute Link

An absolute link contains the complete address. 

<a href="https://example.com">
    Visit Website
</a>

Relative Link

A relative link points to a resource within the current website or project. 

<a href="about.html">
    About
</a>

Fragment Link

A fragment can jump to a specific location on the same page. 

<a href="#contact">
    Jump to Contact
</a>

Complete Example

<a href="https://example.com">
    Absolute Link
</a>

<a href="about.html">
    Relative Link
</a>

<a href="#contact">
    Fragment Link
</a>
Remember:

Absolute = complete web address

Relative = local project/page address

Fragment = location inside a page
