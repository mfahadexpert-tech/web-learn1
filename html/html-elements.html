HTML Elements

An HTML element is a complete unit made from HTML tags and content.

Tag vs Element

A tag is one part of HTML markup. 

<p>

</p>

A complete element includes the opening tag, content and closing tag. 

<p>
    Hello World
</p>

Opening and Closing Tags

Part Example
Opening Tag <p>
Content Hello World
Closing Tag </p>

Elements Can Be Nested

An HTML element can contain another element. 

<p>

    This is
    <strong>
        important
    </strong>

</p>

Correct Nesting

When elements are nested, close the last opened element first.

Memory Rule:

Last opened → first closed

Example

<p>

    Learn
    <strong>
        HTML
    </strong>
    today.

</p>
