HTML Input Types

The <input> element is one of the most commonly used form controls.

Text Input

<input
    type="text"
    name="username"
>

Email Input

<input
    type="email"
    name="email"
>

Password Input

<input
    type="password"
    name="password"
>

Number Input

<input
    type="number"
    name="marks"
>

Date Input

<input
    type="date"
    name="dob"
>

Checkbox

<label>

    <input
        type="checkbox"
        name="skill"
    >

    HTML

</label>

Radio Buttons

Radio buttons with the same name belong to the same group. 

<label>

    <input
        type="radio"
        name="gender"
    >

    Male

</label>


<label>

    <input
        type="radio"
        name="gender"
    >

    Female

</label>

File Input

<input
    type="file"
    name="document"
>

Common Input Types

Type Use
text Normal text
email Email address
password Password
number Numeric value
date Date
checkbox Multiple choices
radio One choice from a group
file Select a file

Fieldset and Legend

Related form controls can be grouped using <fieldset> and <legend>. 

<fieldset>

    <legend>
        Preferred Contact
    </legend>

    <label>
        <input
            type="radio"
            name="contact"
        >
        Email
    </label>

    <label>
        <input
            type="radio"
            name="contact"
        >
        Phone
    </label>

</fieldset>
