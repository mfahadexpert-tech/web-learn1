HTML Headings

HTML headings are used to create a clear content hierarchy.

HTML provides six heading levels: 

<h1> to <h6>

Heading Example

<h1>Web Technologies</h1>

<h2>HTML</h2>

<h3>Forms</h3>

<p>
    HTML structures web content.
</p>

Output

Web Technologies

HTML

Forms

HTML structures web content.

Best Practice

Use headings to describe the structure and hierarchy of the content.

Use CSS when you only want to change the visual size of text.
