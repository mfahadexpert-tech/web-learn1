HTML Images

Images are added to a web page using the <img> element.

Basic Image Syntax

<img
    src="student.jpg"
    alt="Student studying"
    width="400"
>

Image Attributes

Attribute Purpose
src Defines where the image comes from.
alt Provides a text alternative.
width Controls the display width.

Why is alt Important?

The alt attribute provides a description of an informative image.

It is useful for accessibility and can also provide information when the image cannot be displayed.

Example

<img
    src="../assets/images/student.jpg"
    alt="Student studying"
    width="400"
>
Important:

Later, if you add an image named student.jpg, put it inside:

assets/images/
