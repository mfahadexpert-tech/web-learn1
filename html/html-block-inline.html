Block and Inline Elements

HTML elements can behave differently in the document layout.

Block-Level Elements

Block elements normally start on a new line and take the available width.

Examples include: 

<div>
<p>
<h1>
<ul>
<table>

Inline Elements

Inline elements do not normally start on a new line.

They use only the space needed by their content. 

<span>
<a>
<img>
<strong>
<em>
