HTML Audio and Video

HTML5 supports audio and video directly in a web page.

HTML Audio

Use the <audio> element for audio content. 

<audio controls>

    <source
        src="lecture.mp3"
        type="audio/mpeg"
    >

</audio>

HTML Video

Use the <video> element for video content. 

<video
    controls
    width="480"
>

    <source
        src="demo.mp4"
        type="video/mp4"
    >

</video>

The controls Attribute

The controls attribute allows the browser to display media controls such as play, pause and volume controls.

Media Accessibility

Captions or transcripts can make learning media more accessible.

Example File Location

You can later create a media folder if you want to test real audio and video: 

assets/
└── media/
    ├── lecture.mp3
    └── demo.mp4

Do not create it yet unless you have actual audio or video files to use.
