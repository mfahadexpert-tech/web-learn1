HTML Introduction

HTML stands for HyperText Markup Language.

HTML is the basic building block of the Web. It gives structure and meaning to the content of a web page.

What Does HTML Do?

HTML tells the browser what each piece of content represents. 

<h1>Web Technologies</h1>

<p>
    HTML structures web content.
</p>

HTML, CSS and JavaScript

A web page can be understood using three simple parts:

HTML = Structure

CSS = Presentation

JavaScript = Behavior

What is Markup?

Markup means using special tags to describe and organize content.

HTML tags are normally written inside angle brackets: 

<p>Hello World</p>

Here, the paragraph tags tell the browser that the text is a paragraph.

HTML is Not a Programming Language

HTML does not perform calculations or logic like programming languages.

It describes the meaning and structure of web content.

Simple HTML Example

<!DOCTYPE html>
<html>

<head>
    <title>My Page</title>
</head>

<body>

    <h1>Hello World</h1>

    <p>
        My first web page.
    </p>

</body>

</html>
