HTML Form Validation

HTML5 provides attributes that can check user input before a form is submitted.

required

The required attribute means that a field cannot be empty. 

<input
    type="email"
    name="email"
    required
>

Try Required

pattern

The pattern attribute lets an input follow a specific format. 

<input
    name="reg"
    pattern="SP[0-9]{2}-BSSE-[0-9]{3}"
    required
>

Accepted Example

SP24-BSSE-001

Rejected Examples

SP24-BSSE-01

SP24-BSCS-001

min and max

The min and max attributes define boundaries for numeric input. 

<input
    type="number"
    min="0"
    max="100"
>

Try Min and Max

Email Validation

Using type="email" lets the browser check whether the entered value looks like an email address. 

<input
    type="email"
    name="email"
    required
>

Client-Side vs Server-Side Validation

Client Server
Fast feedback Re-validates input
required Security checks
pattern Business rules
min / max Trusted data handling
Important:

Client-side validation improves the user experience, but it does not replace server-side validation.
