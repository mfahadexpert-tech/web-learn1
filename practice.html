Category 1: Responsive Form & Multi-Column Footer

Responsive Layouts

This problem demonstrates a complete real-world web page incorporating a responsive two-column grid form with CSS floats/clears, combined with a modern 4-column dark footer containing brand identity, social links, navigation, contact information, and an interactive message box.

Key Implementation Features

  • Responsive 2-Column Grid: 25% labels and 75% inputs stack seamlessly to 100% full width on viewport screens below 600px.
  • 4-Column CSS Grid Footer: Distinct columns for Brand Info, Quick Navigation Links, Contact Information, and Feedback Form.
  • Brand Header & Theming: Warm gold gradient headers (#ffd700 to #f59e0b) with high-contrast dark accents (#0f172a).

Category 2: Geological Eras & Events Table (Colspan & Rowspan)

HTML Tables

This problem tests advanced table merging techniques using the colspan attribute to unite columns across headers, and nested rowspan cells to group consecutive chronological records into clean multi-row clusters.

Key Implementation Features

  • Column Merging (colspan="2"): Header cell spans across the event description and numerical era value columns.
  • Vertical Row Merging (rowspan="2" & rowspan="3"): Combines 2 rows in the first block and 3 rows in the subsequent block without breaking the cell alignment.
  • Table Boundaries: Classic borders rendered using HTML table attributes and unified box styling.

Category 3: HTML5 Form Validation, Datalist & Attributes

HTML5 Forms

This problem highlights modern HTML5 semantic input types and client-side form validation mechanisms without relying on external libraries. It exercises regex pattern matching, step-based numerical increments, datalist autocomplete dropdowns, and field states (readonly and disabled).

Key Implementation Features

  • Regex Pattern Validation: University registration pattern restriction (pattern="FA[0-9]{2}-BSSE-[0-9]{3}") enforced on submit.
  • Autocomplete Datalist: Dynamic option suggestions (Vehari, Multan, Islamabad) attached to input via list="cities".
  • Constraint Attributes: Numeric step sizing (min="10" max="20" step="5"), readonly phone number, and disabled search URL field.
  • Semantic Grouping: Enclosed inside a styled <fieldset> with descriptive <legend>.
👁 Click Output Preview to Inspect Full Code in Draggable Split View
📄 question3-validation-form.html
SOURCE CODE (HTML5) UTF-8 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Registration & Validation Form</title>
</head>
<body>

    <form action="/register" method="post">
        <fieldset>
            <legend>Form to fill</legend>

            <label for="username">Username:</label>
            <input type="email" id="username" name="username" required autocomplete="email" autofocus>

            <label for="reg">REGISTER:</label>
            <input name="reg" id="reg" pattern="FA[0-9]{2}-BSSE-[0-9]{3}" required>
            <br>

            <label for="password">Password:</label>
            <input type="password" id="password" name="password" required>

            <label for="age">Age:</label>
            <input type="number" id="age" name="age" min="10" max="20" step="5" required>
            <br>

            <label for="cities">Cities:</label>        
            <input list="cities" id="cities-input" name="city">
            <datalist id="cities">
                <option value="vehari">
                <option value="multan">
                <option value="islamabad">
            </datalist>

            <label for="phone">Phone:</label>
            <input type="tel" id="phone" name="phone" pattern="\+92-[0-9]{11}" placeholder="+9234344444444" required readonly>
            <br>

            <label for="search">SEARCH:</label>
            <input type="search" id="search" name="search" required>
            <br>

            <label for="url">Search website here:</label>
            <input type="url" id="url" name="url" disabled>

            <label for="gender">GENDER:</label>
            <input type="radio" id="male" name="gender" value="male" required>
            <label for="male">Male</label>
            <input type="radio" id="female" name="gender" value="female" required>
            <label for="female">Female</label>
            <br>

            <select name="country" id="country" required>
                <option value="">Select a country</option>
                <option value="pakistan">Pakistan</option>
                <option value="usa">USA</option>
                <option value="canada">Canada</option>
                <option value="uk">UK</option>
            </select>

            <label for="date">DATE:</label>
            <input type="date" id="date" name="date" required>

            <label for="address">Address:</label>
            <input type="text" id="address" name="address" required>

            <button type="submit">Register</button>
        </fieldset>
    </form>

</body>
