Lecture 8: Introduction to JavaScript

Bridging the Web triad: JavaScript behavior, DOM concepts, and modern CSS visual effects

Summary

Completing the core web triad (HTML structure, CSS presentation, JavaScript behavior), this lecture introduces JavaScript's role in client-side interactivity, DOM manipulation principles, and event handling. Additionally, it explores advanced pure CSS3 visual capabilities: border-radius, gradients, box-shadows, 2D transforms, smooth transitions, and keyframe animations.

Topics Covered:

  • JavaScript Fundamentals in Web Technologies
    • The Web Triad: Structure (HTML) vs. Presentation (CSS) vs. Behavior (JavaScript)
    • Client-Side Scripting & Browser Execution Engine
    • The Document Object Model (DOM) Tree Concept
    • Methods of Adding Scripts: Inline, Internal (<script>), and External (.js files)
    • Event-Driven Programming Concepts (Clicks, Form submissions)
  • Advanced CSS3 Visual Effects
    • Rounded Corners (border-radius, circular avatars, pill buttons)
    • Gradients: linear-gradient() and radial-gradient() with color stops
    • Drop Shadows: box-shadow (offset, blur, spread) and text-shadow
    • Transparency: opacity vs. RGBA color alpha channels
  • CSS Motion & Animation
    • 2D Transforms: translate(), rotate(), scale(), skew()
    • CSS Transitions: transition property, duration, timing-function
    • CSS Keyframe Animations: @keyframes, from/to, percentages, iteration
Example Code:
/* Pure CSS Animated Interactive Card */
.animated-card {
    background: linear-gradient(135deg, #2b5b9c, #0d9488);
    color: #ffffff;
    padding: 24px;
    border-radius: 12px;
    box-shadow: 0 8px 20px rgba(43, 91, 156, 0.25);
    text-align: center;
    transition: transform 0.3s ease, box-shadow 0.3s ease;
}

.animated-card:hover {
    transform: translateY(-6px) scale(1.02);
    box-shadow: 0 14px 28px rgba(43, 91, 156, 0.35);
}

2. The Document Object Model (DOM) Concept

When an HTML page is loaded, the browser automatically creates a Document Object Model (DOM) of the page. The DOM represents the document as a logical tree structure where every HTML element, attribute, and text block is an accessible node (e.g., document.getElementById()).

Document Root → <html> → <head> / <body> → <header> / <main> / <footer>

3. CSS Transitions vs. Keyframe Animations

Property CSS Transitions CSS @keyframes Animations
Trigger Requirement Requires a state change trigger (e.g., :hover or :focus). Runs automatically on page load without requiring user interaction.
Control Points Only 2 states: start and end. Unlimited intermediate states (using percentages: 0%, 25%, 50%, 100%).
Repetition Executes once per trigger. Can loop infinitely with animation-iteration-count: infinite.
Common Student Mistakes:
  • Confusing CSS opacity with rgba() transparency: opacity turns the element AND all its child text transparent, while rgba() only turns the background color transparent.
  • Forgetting to define a transition-duration (e.g. 0.3s), causing hover effects to jump instantaneously without smoothing.
  • Placing heavy JavaScript logic on pages where pure CSS transitions can achieve the same animation with significantly higher performance.

Lecture 8 Viva Questions & Answers

Q1: What is the Document Object Model (DOM)?
Answer: The DOM is an object-oriented tree representation of the web page constructed by the browser. It allows scripts to dynamically access, inspect, and update HTML elements, styles, and attributes.

Q2: What is the difference between CSS opacity: 0.5 and background-color: rgba(0,0,0,0.5)?
Answer: opacity: 0.5 makes the entire element and all of its nested children/text semi-transparent. rgba(0,0,0,0.5) applies transparency strictly to the background color, keeping child text 100% crisp and readable.

Q3: Name four sub-properties of the CSS animation shorthand.
Answer: 1. animation-name, 2. animation-duration, 3. animation-timing-function, and 4. animation-iteration-count.
