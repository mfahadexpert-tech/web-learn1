Lecture 6: CSS Box Model & Layout

Mastering element geometry, padding, borders, margins, box-sizing, and display behaviors

Summary

Every element on a web page is treated by the browser as a rectangular box. This lecture demystifies the four layers of the CSS Box Model (Content, Padding, Border, Margin), dimensional calculations, the impact of box-sizing (content-box vs. border-box), margin collapse, overflow management, and the fundamental display property values.

Topics Covered:

  • The Four Box Model Layers
    • Content Area: text, images, or child elements
    • Padding: transparent spacing clearing area inside the border
    • Border: decorative edge wrapping content and padding
    • Margin: transparent spacing clearing area outside the border
  • Box Sizing Calculations
    • content-box (default W3C standard: width = content only)
    • border-box (modern standard: width includes content + padding + border)
    • Margin Collapsing behavior between adjacent vertical blocks
  • Dimensions & Overflow Management
    • width, height, min-width, max-width
    • overflow: visible, hidden, scroll, auto
  • The Display Property
    • display: block, display: inline, display: inline-block
    • display: none vs. visibility: hidden
Example Code:
/* Modern Box-Sizing Reset & Card Layout */
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

.box-card {
    width: 300px;
    padding: 20px;
    border: 3px solid #2b5b9c;
    margin: 25px auto;
    background-color: #eaf1fa;
    text-align: center;
}
Output:

Detailed Theoretical Concepts

1. Box Sizing Comparison: content-box vs. border-box

Consider an element styled with width: 300px; padding: 20px; border: 5px solid black;:

Property Value Total Rendered Width Formula Final Screen Width
box-sizing: content-box (Default) Width (300) + Left/Right Padding (40) + Left/Right Border (10) 350px (Box expands unexpectedly, often breaking multi-column layouts).
box-sizing: border-box (Modern Best Practice) Total Width locked at 300px. Padding and border subtract from content space. 300px (Box strictly maintains intended dimension).

2. Display Property Comparison

Display Value Line Break Behavior Width / Height Support Padding / Margin Impact
block Forces a new line before and after. Supports explicit width and height. All 4 sides (top, right, bottom, left) push surrounding elements.
inline Flows horizontally alongside text. Ignores width and height properties. Vertical margins and padding do not push neighboring lines.
inline-block Flows inline like text on the same line. Supports explicit width and height. All 4 sides cleanly push surrounding elements.

3. display: none vs. visibility: hidden

CSS Rule Visibility on Screen DOM Layout Space
display: none; Completely hidden. Removes the space entirely. Adjacent elements collapse as if the element does not exist.
visibility: hidden; Completely hidden. Preserves empty blank space. Element remains in layout flow like an invisible footprint.
Common Student Mistakes:
  • Forgetting that vertical margins collapse (e.g. if one element has margin-bottom: 20px and the next has margin-top: 30px, the resulting gap is 30px, not 50px).
  • Attempting to assign width or height to inline elements (such as <span> or <a>) without first changing their display to inline-block or block.
  • Failing to apply the universal * { box-sizing: border-box; } reset, causing padding to accidentally overflow parent containers.

Lecture 6 Viva Questions & Answers

Q1: What is the CSS Box Model? Name its four components from inside out.
Answer: The box model is the rectangular wrapping around every HTML element. From the center outwards: 1. Content, 2. Padding, 3. Border, and 4. Margin.

Q2: What is margin collapsing?
Answer: When the vertical top and bottom margins of two adjacent block elements touch, they combine into a single margin whose size equals the larger of the two margins, rather than their sum.

Q3: How does overflow: auto differ from overflow: scroll?
Answer: scroll forces permanent scrollbars even when content fits inside the box. auto adds scrollbars dynamically only when the content actually exceeds the container dimensions.

Practice Lab Task 6
