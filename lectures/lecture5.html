Lecture 5: CSS Selectors

Targeting elements with combinators, pseudo-classes, pseudo-elements, and specificity rules

Summary

CSS Selectors define which HTML elements are targeted by CSS declarations. This lecture examines basic selectors, combinator relationships (child, adjacent, sibling), pseudo-classes for interactive states, pseudo-elements for virtual content, and the mathematical rules governing CSS Cascade, Specificity, and Property Inheritance.

Topics Covered:

  • Core Selectors
    • Element, Class (.class), ID (#id)
    • Universal (*) and Grouping (h1, h2, h3)
    • Attribute Selectors: [type="email"], [href^="https"]
  • CSS Combinators
    • Descendant Selector (space): targets any nested descendant
    • Child Selector (>): targets direct immediate children only
    • Adjacent Sibling (+): targets the very next sibling element
    • General Sibling (~): targets all following sibling elements
  • Pseudo-Classes & Pseudo-Elements
    • Interactive Pseudo-classes: :hover, :active, :focus, :visited
    • Structural Pseudo-classes: :first-child, :last-child, :nth-child(even/odd)
    • Pseudo-Elements: ::before, ::after, ::first-letter, ::placeholder
  • Cascade, Specificity & Inheritance
    • Specificity Weight: Inline (1000) > ID (100) > Class (10) > Element (1)
    • Source Order Priority & Property Inheritance (inherit, initial, unset)
Example Code:
/* Combinator & Pseudo-Class Examples */
ul.menu > li {

ul.menu > li:hover {

}

ul.menu > li:first-child {
    font-weight: bold;
    border-bottom: 2px solid #2b5b9c;
}

button:focus {
    outline: 2px solid #2b5b9c;
}

Detailed Theoretical Concepts

1. The Four CSS Combinators

Combinator Name Syntax Exact Matching Condition
Descendant Selector div p Matches any <p> that is anywhere inside a <div>, regardless of nesting depth.
Child Selector div > p Matches only <p> elements that are direct immediate children of a <div>.
Adjacent Sibling h2 + p Matches the single <p> immediately following an <h2> with the same parent.
General Sibling h2 ~ p Matches every <p> that shares the same parent and follows an <h2>.

2. CSS Specificity Hierarchy

When conflicting CSS rules target the same element, the browser calculates specificity to decide the winner:

Selector Level Weight Value Example
Inline Style1, 0, 0, 0 (Highest)style="color: red;"
ID Selector0, 1, 0, 0#main-header
Class / Attribute / Pseudo-class0, 0, 1, 0.nav-link, [type="text"], :hover
Element / Pseudo-element0, 0, 0, 1p, h1, ::before
Universal / Combinator0, 0, 0, 0 (Zero)*, >, +, ~
Common Student Mistakes:
  • Confusing Class (.name) with ID (#name). An ID must be unique per HTML page, whereas a class can be applied to any number of elements.
  • Confusing pseudo-classes (single colon :hover, denoting an element state) with pseudo-elements (double colon ::before, denoting virtual DOM parts).
  • Assuming div > p will select paragraphs nested inside a child section (that requires descendant div p).

Lecture 5 Viva Questions & Answers

Q1: What is the difference between a Child Selector (>) and a Descendant Selector (space)?
Answer: The child selector (parent > child) selects only direct, immediate children of the parent. The descendant selector (ancestor descendant) selects all matching elements regardless of how deeply nested they are.

Q2: If an element has rules from both an ID selector and a Class selector, which one applies?
Answer: The ID selector wins because its specificity value (0,1,0,0 = 100) is ten times higher than a class selector (0,0,1,0 = 10).

Q3: What is the purpose of the ::before and ::after pseudo-elements?
Answer: They allow developers to insert cosmetic content or decorative styling directly before or after an element's content using CSS alone, via the content: ""; property without adding extra HTML markup.
