Lecture 4: Introduction to CSS

Styling web pages with CSS syntax, color models, typography, and background properties

Summary

Cascading Style Sheets (CSS) separate content structure from visual presentation. This lecture introduces CSS syntax rules (selectors, properties, values), the three implementation methods (inline, internal, external), color representations (Hex, RGB, RGBA), typography properties, text formatting, and background styling.

Topics Covered:

  • CSS Fundamentals
    • Purpose of CSS & Separation of Concerns
    • CSS Rule Syntax: Selector, Property, Value, Declaration
  • Three Methods of Applying CSS
    • Inline Styles: style attribute directly on HTML elements
    • Internal Styles: <style> block inside <head>
    • External Stylesheets: <link rel="stylesheet" href="style.css">
  • Colors & Units
    • Named Colors, Hexadecimal (#RRGGBB)
    • RGB and RGBA (Alpha channel transparency)
  • Typography & Text Styling
    • font-family, font-size, font-weight, font-style
    • Generic Font Families: Serif, Sans-Serif, Monospace
    • text-align, text-decoration, text-transform, line-height
  • CSS Backgrounds
    • background-color, background-image, background-repeat, background-size
Example Code:
/* External CSS file: style.css */
body {
    font-family: Arial, sans-serif;
    background-color: #f8fafc;
    color: #1e293b;
}

.course-box {
    background-color: #ffffff;
    border: 2px solid #2b5b9c;
    border-radius: 6px;
    padding: 16px;
    text-align: center;
}

.course-box h2 {
    color: #2b5b9c;
    text-transform: uppercase;
    letter-spacing: 1px;
}

Detailed Theoretical Concepts

1. Three Ways to Insert CSS

Method Syntax Example Advantages Disadvantages
Inline CSS <h1 style="color: blue;"> Applies quick isolated styles; highest specificity in normal cascade. Cannot be reused; pollutes HTML; very difficult to maintain.
Internal CSS <head><style> p { color: red; } </style> Styles an entire single webpage in one document. Cannot style multiple HTML pages across a multi-page website.
External CSS <link rel="stylesheet" href="style.css"> Industry standard. Reusable across 100s of pages; browser caches file for speed. Requires an additional HTTP request (cached subsequently).

2. CSS Color Models Comparison

  • Named Colors: Standard keywords like red, blue, green (140 standard CSS names).
  • Hexadecimal: 6-character hex code representing Red, Green, Blue from #000000 (black) to #ffffff (white). Example: #2b5b9c.
  • RGB: rgb(red, green, blue) with values from 0 to 255. Example: rgb(43, 91, 156).
  • RGBA: Adds the Alpha parameter for opacity from 0.0 (fully transparent) to 1.0 (fully opaque). Example: rgba(43, 91, 156, 0.5).

3. Typography: Generic Font Families

Generic Family Visual Characteristics Common Font Examples
Sans-serifClean strokes with no decorative feet; modern and highly readable on digital screens.Arial, Helvetica, Segoe UI, Roboto
SerifFeatures decorative serifs (feet/tails) on letter edges; formal and traditional for print.Times New Roman, Georgia, Garamond
MonospaceEvery character occupies the exact same fixed width; essential for programming code.Courier New, Consolas, Monaco
Common Student Mistakes:
  • Forgetting the semicolon (;) at the end of each CSS declaration, which invalidates all following rules in the block.
  • Omitting the # symbol before hexadecimal color codes (e.g. writing color: ffffff; instead of #ffffff;).
  • Over-relying on Inline CSS instead of maintaining clean separation with External stylesheets.

Lecture 4 Viva Questions & Answers

Q1: What are the main components of a CSS rule?
Answer: A CSS rule consists of a Selector (pointing to the HTML element to style) and a Declaration Block containing one or more declarations. Each declaration has a Property, a colon, and a Value followed by a semicolon.

Q2: Why is External CSS considered best practice over Inline CSS?
Answer: External CSS cleanly separates structure from presentation, allows one stylesheet to control hundreds of web pages simultaneously, reduces file sizes, and is cached by browsers for faster loading.

Q3: What is the difference between RGB and RGBA?
Answer: RGB specifies color channels (Red, Green, Blue) from 0 to 255. RGBA includes a 4th parameter, Alpha (ranging from 0.0 to 1.0), which dictates the transparency of that specific color without altering the opacity of child text.
