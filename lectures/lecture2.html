Lecture 2: HTML Basics

Foundations of HTML document structure, text formatting, hyperlinks, and lists

Summary

HTML (HyperText Markup Language) is the standard markup language used to structure web pages and their content. This lecture explores fundamental document structure, tags versus elements, attributes, headings from h1 to h6, paragraphs, inline text formatting, ordered and unordered lists, hyperlinks, and image embedding.

Topics Covered:

  • HTML Core Foundations
    • HTML Definition & Role of Markup
    • Tags, Elements, and Attributes Syntax
    • Parent and Child Nesting & The Document Object Model (DOM)
  • Document Structure
    • <!DOCTYPE html> Declaration
    • <html>, <head>, <title>, <body>, and <meta> Tags
  • Text Formatting & Typography
    • Headings (<h1> through <h6>)
    • Paragraphs (<p>), Line Breaks (<br>), Horizontal Rules (<hr>)
    • Semantic Text: <strong>, <em>, <mark>, <del>, <ins>
  • Hyperlinks & Media
    • Anchor Tag (<a>) with href (Absolute vs. Relative vs. Fragment Links)
    • Images (<img>) with src, alt, width, and height
    • Lists: Ordered (<ol>), Unordered (<ul>), and Description (<dl>)
Example Code:
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First HTML Page</title>
</head>
<body>
    <h1>Getting Started with HTML</h1>
    <p>HTML uses <strong>tags</strong> to describe the structure of web pages.</p>
    
    <h2>Core Web Languages</h2>
    <ul>
        <li><strong>HTML:</strong> Content and Structure</li>
        <li><strong>CSS:</strong> Presentation and Styling</li>
        <li><strong>JavaScript:</strong> Interactivity and Logic</li>
    </ul>

    <p>Visit <a href="../index.html">WebLearn Homepage</a> for more lectures.</p>
</body>
</html>

HTML uses tags to describe the structure of web pages.

Detailed Theoretical Concepts

1. Anatomy of an HTML Element

An element comprises the opening tag, attributes, enclosed content, and the closing tag:

<p class="highlight"> Hello Web </p>

  • Opening Tag: <p> marks where the element begins.
  • Attribute: class="highlight" gives metadata/styling hooks to the element.
  • Content: Hello Web is the text node rendered in the browser.
  • Closing Tag: </p> marks where the element ends.
  • Void (Self-Closing) Elements: Elements that have no content or closing tag, such as <img>, <br>, <hr>, and <input>.

2. Heading Hierarchy Best Practices

HTML provides six levels of headings:

Tag Importance Standard Usage Guideline
<h1>HighestMain page topic. Exactly one <h1> should be used per web page for SEO.
<h2>SecondaryMajor section headers.
<h3>Sub-sectionSub-topics nested under an <h2>.
<h4>–<h6>Lower levelsDetailed category headings and sub-groupings.

3. Types of URLs in Hyperlinks

Link Type Syntax Example When to Use
Absolute URL https://www.w3.org Linking to external websites on different domains. Includes full protocol and domain.
Relative URL lecture3.html or ../css/style.css Linking to files located within your own local project folder structure.
Fragment Identifier #summary Jumps directly to an element with id="summary" on the same page.
Common Student Mistakes:
  • Skipping the alt attribute on <img> tags, which breaks accessibility for screen-readers and displays nothing if the image file fails to load.
  • Nesting tags incorrectly: e.g. writing <strong><em>Text</strong></em> instead of closing tags in reverse order of opening (<strong><em>Text</em></strong>).
  • Using multiple <h1> tags simply to make text bigger instead of using CSS for sizing.

Lecture 2 Viva Questions & Answers

Q1: What is the purpose of the <!DOCTYPE html> declaration?
Answer: It informs the browser that the document is written in modern HTML5, ensuring the browser renders the page in "standards mode" rather than legacy "quirks mode".

Q2: What is the difference between an HTML tag and an HTML element?
Answer: A tag is the opening or closing bracket marker (e.g. <p> or </p>). An element consists of the entire unit from start tag through the attributes, content, and end tag.

Q3: Explain the three types of HTML lists.
Answer: 1. Ordered List (<ol>) for numbered sequences. 2. Unordered List (<ul>) for bulleted items. 3. Description List (<dl>) with terms (<dt>) and descriptions (<dd>).
