Detailed Theoretical Concepts

1. Internet vs. World Wide Web (WWW)

A common beginner mistake is confusing the Internet with the World Wide Web:

Concept Definition Example Services
The Internet The massive physical infrastructure of interconnected computer networks worldwide. Email (SMTP), File Transfer (FTP), Web (HTTP), Streaming.
World Wide Web A high-level service operating on top of the Internet using HTTP and hyperlinks to share documents. Websites, HTML web pages, web applications.

2. The Client-Server Request-Response Flow

Every web interaction operates through this structured lifecycle:

Client (Browser) → HTTP Request → Internet & DNS → Web Server → HTTP Response (HTML/CSS) → Browser Rendering

  • Client (Browser): Submits user requests and parses HTML/CSS for presentation.
  • Web Server: Listens for incoming HTTP requests on port 80 (HTTP) or 443 (HTTPS) and returns requested assets.

3. URL Anatomy Breakdown

Given the standard course example address: https://www.example.com:443/courses/web?id=101#html

Part Value Role & Function
Scheme (Protocol)https://Indicates the secure encrypted protocol used.
SubdomainwwwSub-division under the registered domain name.
Domain Nameexample.comHuman-readable name mapped to a server's IP address.
Port:443Network port on the host (443 is default for HTTPS).
Path/courses/webLocation of the resource on the server directory structure.
Query String?id=101Key-value pairs sending data to the server.
Fragment ID#htmlAnchor pointing directly to an element within the page.

4. HTTP Status Code Categories

HTTP responses return a 3-digit status code informing the client of the outcome:

Class Category Key Examination Example
1xxInformational100 Continue
2xxSuccess200 OK — Request succeeded normally.
3xxRedirection301 Moved Permanently
4xxClient Error404 Not Found — URL does not exist on server.
5xxServer Error500 Internal Server Error — Server encountered an unexpected fault.
Common Student Mistakes:
  • Writing file paths with backslashes (\) instead of forward slashes (/) in web URLs.
  • Assuming a website saved locally on C:\ is publicly accessible on the Internet.
  • Confusing HTTP GET (data passed visibly in URL query string) with HTTP POST (data passed securely in request body).

Lecture 1 Viva Questions & Answers

Q1: What is DNS and what analogy describes it best?
Answer: The Domain Name System (DNS) translates human-friendly domain names (e.g., google.com) into computer-routable IP addresses (e.g., 142.250.190.46). It operates exactly like a phonebook contact list.

Q2: What is the difference between a static website and a dynamic website?
Answer: A static website delivers pre-written, identical HTML/CSS files to all visitors. A dynamic website generates HTML in real-time on the server using database queries and application logic.

Q3: Name the three tiers in standard 3-tier web architecture.
Answer: 1. Presentation Tier (UI / HTML & CSS), 2. Application Logic Tier (Business processing), 3. Data Tier (Database management system).
