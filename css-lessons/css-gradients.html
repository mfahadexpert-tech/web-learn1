CSS Gradients

A gradient creates a smooth transition between two or more colors.

Linear Gradient

background:
    linear-gradient(
        90deg,
        #376fb4,
        #48a9a6
    );
Linear Gradient

Gradient Directions

Direction Meaning
90deg Left to right
180deg Top to bottom
45deg Diagonal

Multiple Colors

background:
    linear-gradient(
        90deg,
        #376fb4,
        #48a9a6,
        #8e6bbd
    );
Multiple Color Stops

Radial Gradient

background:
    radial-gradient(
        circle,
        #ffffff,
        #dceafa
    );
Radial Gradient

Gradient Overlay

A semi-transparent gradient can be combined with an image to improve text readability. 

.hero {
    background:
        linear-gradient(
            rgba(0, 0, 0, 0.55),
            rgba(0, 0, 0, 0.15)
        ),
        url("campus.jpg")
        center / cover;

    color: white;
}
Remember:

Gradients should support readability, not make the interface difficult to read.
