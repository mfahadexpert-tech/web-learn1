CSS Box Sizing

The box-sizing property controls how width and height are calculated.

content-box

This is the default box-sizing behavior. 

.box {
    box-sizing: content-box;

    width: 300px;

    padding: 20px;

    border: 5px solid blue;
}

Here, the 300px width applies to the content only.

Padding and border are added outside it.

border-box

.box {
    box-sizing: border-box;

    width: 300px;

    padding: 20px;

    border: 5px solid blue;
}

With border-box, the declared width includes content, padding, and border.

Comparison

content-box border-box
Width = content Width = full box
Padding is added Padding is included
Border is added Border is included
