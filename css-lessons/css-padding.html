CSS Padding

Padding creates space inside an element, between the content and the border.

Basic Padding

.box {
    padding: 20px;
}

Padding Shorthand

padding: 20px;

One value applies to all sides. 

padding:
    10px
    20px
    30px
    40px;
Order:

Top → Right → Bottom → Left
