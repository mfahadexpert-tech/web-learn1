CSS Display

The display property controls how an element participates in page layout.

Common Display Values

Value Behavior
block Starts on a new line
inline Stays in the current line
inline-block Inline placement with box-like sizing
none Element is not displayed

display: block

.item {
    display: block;
}
First Block Second Block

display: inline

.item {
    display: inline;
}
First Second Third

display: inline-block

.item {
    display: inline-block;

    width: 130px;

    padding: 15px;
}
Item 1 Item 2

display: none

.hidden {
    display: none;
}

The element is removed from the visual layout.

Remember:

block = new line

inline = same line

inline-block = same line + width/height control

none = hidden from layout
