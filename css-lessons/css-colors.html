CSS Colors

The color property controls the text or foreground color of an element.

Basic Example

p {
    color: blue;
}

Common Color Formats

Format Example
Named blue
HEX #0066cc
RGB rgb(0, 102, 204)
RGBA rgba(0, 102, 204, 0.5)

HEX Color

h1 {
    color: #1f4e79;
}

RGB Color

p {
    color: rgb(40, 40, 40);
}

RGBA Color

RGBA includes an alpha value for transparency. 

.note {
    color: rgba(35, 142, 139, 0.7);
}

Visual Example

Remember:

RGBA adds transparency using the alpha value.

Alpha normally ranges from 0 to 1.
