CSS Text

CSS provides properties for controlling alignment, decoration, capitalization, and text spacing.

text-align

h1 {
    text-align: center;
}

Common values: 

left
center
right
justify

text-decoration

a {
    text-decoration: none;
}

Other values include: 

underline
overline
line-through

text-transform

h2 {
    text-transform: uppercase;
}

Other values: 

lowercase
capitalize

line-height

p {
    line-height: 1.6;
}

Line height controls the vertical distance between lines of text.

letter-spacing

h1 {
    letter-spacing: 2px;
}

Complete Example

.title {
    text-align: center;
    text-transform: uppercase;
    letter-spacing: 2px;
}

p {
    line-height: 1.6;
}

a {
    text-decoration: none;
}
