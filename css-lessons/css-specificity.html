CSS Specificity

Specificity describes the relative strength of selectors when competing rules target the same element.

Common Specificity Levels

Selector Specificity
#title 1-0-0
.card 0-1-0
input[type="text"] 0-1-1
p 0-0-1
* 0-0-0

Example

p {
    color: green;
}

.note {
    color: blue;
}

#intro {
    color: red;
}
<p
    id="intro"
    class="note"
>
    Hello CSS
</p>

What Happens?

All three selectors match the paragraph.

p 0-0-1
.note 0-1-0
#intro 1-0-0
Result:

The ID selector has the stronger specificity.

Final text color: red.
