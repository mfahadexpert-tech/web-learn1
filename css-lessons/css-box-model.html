CSS Box Model

Every HTML element is treated as a rectangular box.

The box model has four main layers:

  • Content
  • Padding
  • Border
  • Margin

Visual Box Model

Margin
Border
Padding
Content

Content

The content area contains the actual text, image, or child elements. 

.box {
    width: 300px;
    height: 100px;
}

Padding

Padding creates space between the content and the border. 

.box {
    padding: 20px;
}

Border

The border surrounds the padding and content. 

.box {
    border: 3px solid blue;
}

Margin

Margin creates space outside the border. 

.box {
    margin: 30px;
}

Complete Example

.box {
    width: 250px;

    padding: 20px;

    border:
        5px solid black;

    margin: 30px;
}

Total Width

With the default content-box sizing: 

width = 250px

padding-left = 20px
padding-right = 20px

border-left = 5px
border-right = 5px

Total = 300px
Memory Rule:

Content → Padding → Border → Margin
