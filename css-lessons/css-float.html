CSS Float

The float property moves an element to the left or right and allows surrounding content to wrap around it.

float: left

.photo {
    float: left;

    width: 150px;

    margin-right: 18px;

    margin-bottom: 8px;
}
IMAGE

This text wraps beside the floated element. More text continues around the available space next to the float.

float: right

.photo {
    float: right;

    width: 150px;

    margin-left: 18px;
}

Two Floats

.left {
    float: left;

    width: 45%;
}

.right {
    float: right;

    width: 45%;
}

clear

The clear property controls whether an element can sit beside preceding floats.

Value Meaning
clear: left Move below left floats
clear: right Move below right floats
clear: both Move below floats on both sides

Clearfix

A clearfix helps a parent contain floated children. 

.container::after {
    content: "";

    display: table;

    clear: both;
}

Common Float Problems

  • Parent height can collapse
  • Widths and margins can exceed the container
  • Text can touch the floated element
  • Content may need clear
  • Overflow can hide useful content
Use Float When:

You want text to wrap around an image.

Or when maintaining an older float-based layout.
