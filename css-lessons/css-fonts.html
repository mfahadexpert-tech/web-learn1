CSS Fonts

CSS font properties control the typeface, size, weight, and style of text.

font-family

body {
    font-family: Arial, sans-serif;
}

A fallback font should be provided after the preferred font.

Font Families

  • serif
  • sans-serif
  • monospace
  • cursive
  • fantasy

Font Stack Example

font-family:
    "Trebuchet MS",
    Arial,
    sans-serif;

font-size

h1 {
    font-size: 32px;
}

Common units include: 

px
em
rem
%
vw

font-weight

strong {
    font-weight: 700;
}

Common values include: 

normal
bold
100
200
...
900

font-style

em {
    font-style: italic;
}

Complete Example

.title {
    font-family: Georgia, serif;
    font-size: 32px;
    font-weight: 700;
    font-style: italic;
}

Font Types

Family Typical Use
Serif Headings and larger text
Sans-serif Body text
Monospace Code listings
Cursive Short decorative text
Fantasy Special visual effects
