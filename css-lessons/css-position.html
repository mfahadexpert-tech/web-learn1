CSS Position

The position property controls how an element is placed on a page.

Position Types

Position Behavior
static Normal document flow
relative Normal position + visual offset
absolute Positioned using a containing block
fixed Usually positioned relative to viewport
sticky Scroll-aware position

position: static

Static is the default positioning mode. 

.box {
    position: static;

    top: 30px;
}

Offset properties such as top do not move a static element.

position: relative

.notice {
    position: relative;

    left: 30px;

    top: 10px;
}

The element keeps its original space, but is visually shifted.

position: absolute

.card {
    position: relative;
}

.badge {
    position: absolute;

    top: 10px;

    right: 10px;
}

Why position: relative on the Parent?

A relatively positioned parent can provide a predictable reference point for an absolutely positioned child.

position: fixed

.help {
    position: fixed;

    right: 20px;

    bottom: 20px;
}

A fixed element remains at the same viewport location while the page scrolls.

position: sticky

.section-title {
    position: sticky;

    top: 0;
}

Sticky behaves normally until a scroll threshold is reached.
