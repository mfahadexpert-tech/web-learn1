CSS Introduction

CSS stands for Cascading Style Sheets.

CSS controls how HTML elements look and how they are arranged on a web page.

What Can CSS Control?

  • Colors
  • Fonts
  • Spacing
  • Borders
  • Dimensions
  • Positioning
  • Layout
Simple Rule:

HTML = Content

CSS = Presentation

Without CSS

<h1>Welcome</h1>

<p>
    Learn CSS today.
</p>

With CSS

h1 {
    color: darkblue;
}

p {
    font-size: 20px;
}

Output

Welcome

Learn CSS today.
