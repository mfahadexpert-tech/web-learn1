CSS Selectors

CSS selectors are used to choose which HTML elements receive a style.

Element Selector

p {
    color: blue;
    font-size: 22px;
}

This selects all <p> elements.

Class Selector

.highlight {
    background: yellow;
    font-weight: bold;
}
<p class="highlight">
    Important
</p>

Classes can be reused on multiple elements.

ID Selector

#mainTitle {
    color: green;
    font-size: 30px;
}
<h1 id="mainTitle">
    Welcome
</h1>

An ID normally identifies one unique element on the page.

Attribute Selector

input[type="text"] {
    border: 2px solid blue;
}

Grouping Selector

h1,
h2,
p {
    color: navy;
}

Grouping lets several selectors share the same declarations.

Descendant Selector

.card p {
    color: red;
    font-weight: bold;
}
<div class="card">

    <p>
        Inside card
    </p>

</div>

Universal Selector

* {
    margin: 0;
    padding: 0;
}
Selector Symbols:

Element → p

Class → .name

ID → #name

Attribute → [type="text"]

Universal → *
