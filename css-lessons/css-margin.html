CSS Margin

Margin creates space outside the border of an element.

Basic Margin

.box {
    margin: 30px;
}

Margin Shorthand

margin: 20px;

One value applies to all four sides. 

margin: 10px 20px;

Two values: 

top / bottom = 10px
left / right = 20px
margin:
    10px
    20px
    30px
    40px;

Four values follow:

TRBL

Top → Right → Bottom → Left

Margin Collapsing

Certain vertical margins can combine into one margin instead of being added together. 

h2 {
    margin-bottom: 30px;
}

p {
    margin-top: 20px;
}

Instead of: 

30px + 20px = 50px

The resulting vertical gap can become: 

max(30px, 20px)
= 30px

Larger Vertical Margin

.one {
    margin-bottom: 40px;
}

.two {
    margin-top: 60px;
}

The collapsed margin becomes: 

60px
Important:

Margin collapsing mainly affects vertical margins.

Horizontal margins do not collapse in the same way.
