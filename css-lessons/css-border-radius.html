CSS Border Radius

The border-radius property rounds the corners of an element.

Basic Rounded Corners

.card {
    border-radius: 16px;
}

Create a Circle

When width and height are equal, border-radius: 50% can create a circle. 

.avatar {
    width: 100px;

    height: 100px;

    border-radius: 50%;
}
