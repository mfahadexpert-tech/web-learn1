CSS Pseudo-Classes

A pseudo-class selects an element when it is in a particular state or condition.

Basic Syntax

selector:pseudo-class {
    property: value;
}

:hover

The :hover pseudo-class applies when the pointer is over an element. 

a:hover {
    color: red;
    text-decoration: underline;
}

:focus

The :focus pseudo-class applies when an element receives focus. 

input:focus {
    border: 2px solid teal;
    outline: none;
}

:disabled

button:disabled {
    opacity: 0.5;
}

Structural Pseudo-Classes

li:first-child {
    color: green;
}

li:last-child {
    color: blue;
}

li:nth-child(2) {
    color: red;
}

Common Pseudo-Classes

Pseudo-Class Meaning
:hover Pointer is over the element
:focus Element has focus
:active Element is being activated
:visited Visited link
:disabled Disabled control
:nth-child() Selects by position
Memory Rule:

Pseudo-class = state, condition, or position.

It uses one colon: :
