CSS Inheritance

Some CSS properties can be passed from a parent element to its children.

Example

body {
    color: navy;
    font-family: Arial;
}
<div>

    <p>
        Hello
    </p>

</div>

The paragraph can inherit color and font-family from the body.

Often Inherited

  • color
  • font-family
  • font-size
  • line-height
  • text-align

Often Not Inherited

  • margin
  • padding
  • border
  • width
  • height

Inheritance Keywords

color: inherit;

color: initial;

color: unset;

color: revert;
Keyword Meaning
inherit Use the parent's value
initial Use the property's initial value
unset Inherited if naturally inherited, otherwise initial

Example with inherit

body {
    color: navy;
}

.special {
    color: inherit;
}
Remember:

Not every CSS property is inherited.
