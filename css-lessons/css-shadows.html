CSS Shadows

The box-shadow property adds a shadow around an element.

Basic Box Shadow

.card {
    box-shadow:
        0
        8px
        24px
        rgba(0, 0, 0, 0.15);
}

Learn web development.

Box Shadow Syntax

box-shadow:
    offset-x
    offset-y
    blur-radius
    spread-radius
    color;

Example Breakdown

box-shadow:
    0
    8px
    24px
    0
    rgba(0, 0, 0, 0.15);
Value Meaning
0 Horizontal shift
8px Vertical shift
24px Blur radius
0 Spread radius

Course Card Example

.course-card {
    background: white;

    border-radius: 16px;

    padding: 24px;

    box-shadow:
        0 6px 20px
        rgba(0, 0, 0, 0.12);
}

Inset Shadow

.input {
    box-shadow:
        inset
        0
        2px
        5px
        rgba(0, 0, 0, 0.12);
}
Good Practice:

Soft shadows usually look more natural than very dark, heavy shadows.
