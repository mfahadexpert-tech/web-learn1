CSS Combinators

Combinators describe relationships between HTML elements.

Four Main Combinators

Combinator Meaning
Space Descendant
> Direct child
+ Adjacent sibling
~ General sibling

1. Descendant

.menu p {
    color: blue;
}
<div class="menu">

    <p>Home</p>

    <section>
        <p>Products</p>
    </section>

</div>

Both paragraphs are descendants of .menu.

2. Child

div > p {
    color: blue;
}

This selects only direct child paragraphs.

3. Adjacent Sibling

h2 + p {
    color: green;
}
<h2>Introduction</h2>

<p>First paragraph</p>

<p>Second paragraph</p>

Only the first paragraph immediately after the heading is selected.

4. General Sibling

h2 ~ p {
    color: purple;
}

This can select matching later siblings.

Complete Example

/* Descendant */
.box p {
    color: blue;
}

/* Child */
.box > h2 {
    color: navy;
}

/* Adjacent sibling */
h2 + p {
    font-weight: bold;
}

/* General sibling */
h2 ~ p {
    text-decoration: underline;
}
