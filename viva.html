University Viva Voce & Oral Exam Preparation

Comprehensive question-and-answer guide categorized across university Lectures 1 through 8

Module 1: Web Fundamentals (Lectures 1 & 2)

Q1: What is the exact difference between the Internet and the World Wide Web?

Answer: The Internet is the global physical infrastructure of interconnected hardware networks, routers, and cables. The World Wide Web (WWW) is an information-sharing service that runs on top of the Internet, utilizing HTTP and hyperlinks to navigate between HTML documents.

Q2: How does DNS work, and what real-world analogy describes it?

Answer: The Domain Name System (DNS) is the internet's phonebook. Computers communicate using numeric IP addresses (e.g. 142.250.190.46), but humans remember domain names (e.g. google.com). When you type a URL, the browser queries DNS servers to resolve the domain into its corresponding IP address.

Q3: Differentiate between HTTP and HTTPS. What does the "S" represent?

Answer: HTTP sends data across the network in plaintext, making it vulnerable to packet interception. HTTPS (HyperText Transfer Protocol Secure) encrypts all communication using TLS/SSL (Transport Layer Security), safeguarding passwords, payment data, and sensitive inputs.

Q4: Compare Multi-Page Applications (MPA) and Single-Page Applications (SPA).

Answer: In an MPA, every link click requests a brand-new HTML page from the web server, triggering a full browser refresh. In an SPA, the browser loads a single shell HTML page once, dynamically updating view sections via JavaScript API calls without reloading the page.

Module 2: HTML & HTML5 (Lectures 3 & 4)

Q5: What is the difference between an HTML tag and an HTML element?

Answer: A tag is the markup indicator bounded by angle brackets (such as <p> or </p>). An element consists of the entire construct: opening tag, attributes, enclosed content, and the closing tag.

Q6: Why is Semantic HTML critical for modern web development?

Answer: Semantic HTML tags (such as <header>, <nav>, <main>, <article>, <footer>) convey programmatic meaning to web browsers, screen-readers, and search engines. They dramatically improve SEO rankings, code readability, and accessibility for disabled individuals.

Q7: What is the fundamental difference between Block and Inline elements?

Answer: Block elements (e.g., <div>, <p>, <h1>) always start on a fresh line, expand across the full available container width, and respect height and width. Inline elements (e.g., <span>, <a>, <strong>) flow seamlessly within surrounding text and ignore explicit width and height properties.

Q8: When should a developer use form method="POST" instead of method="GET"?

Answer: Use POST for passwords, personal data, and large file uploads because POST submits data inside the request body rather than visibly appending it to the browser URL address bar. Use GET for non-sensitive, bookmarkable search queries.

Module 3: CSS Fundamentals (Lectures 5 & 6)

Q9: Explain the CSS Specificity hierarchy and how conflicts are resolved.

Answer: Specificity is a four-tier calculation: Inline styles (1000) > ID selectors (100) > Class, Attribute, and Pseudo-classes (10) > Element tags and Pseudo-elements (1). If two conflicting rules have identical specificity, the rule written lowest in source order wins (cascade rule).

Q10: What is the CSS Box Model, and why is `box-sizing: border-box` universally favored?

Answer: The box model consists of Content, Padding, Border, and Margin. Under the default content-box, adding padding or borders expands the element beyond its defined width. Under border-box, the padding and border are absorbed inside the defined width, preventing layout breakage.

Q11: Differentiate between `display: none` and `visibility: hidden`.

Answer: display: none removes the element entirely from the layout flow, collapsing its space as though it never existed. visibility: hidden hides the element visually, but preserves its exact physical dimensions as empty blank space.

Module 4: Advanced CSS & JavaScript (Lectures 7 & 8)

Q12: Detail the five CSS positioning values.

Answer: 1. static: Normal document flow; offsets are ignored. 2. relative: Offsets relative to its normal position while preserving its original space footprint. 3. absolute: Removed from flow and positioned relative to its closest non-static ancestor. 4. fixed: Removed from flow and anchored relative to the viewport; stays locked during scroll. 5. sticky: Hybrid that acts static until a scroll threshold is met, then pins like fixed.

Q13: Why does `z-index` sometimes fail to stack an element on top?

Answer: z-index only works on positioned elements (those with position: relative, absolute, fixed, or sticky). On elements with default position: static, z-index has no effect.

Q14: What is the Front-End Web Triad?

Answer: HTML provides the Structure (the skeleton), CSS provides the Presentation (visual styling and skin), and JavaScript provides the Behavior (interactivity, event handling, and logic).
